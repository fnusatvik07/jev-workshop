# Jev Workshop

Teaching materials for a hands-on workshop on **Jev**, the first System One model, built by
[TypeSafe AI](https://typesafe.ai). Jev does not generate text: it evaluates typed questions
against a state and returns typed answers with calibrated probabilities that code can branch
on directly.

Everything in this folder was built and verified against the live API (`typesafe-sdk` 0.7.5,
Jev 1.13 / 1.14) in October 2026. Every notebook executes top to bottom.

## Setup

Python 3.10+ and an API key from the [TypeSafe console](https://console.typesafe.ai/keys).

```bash
pip install typesafe-sdk jupyter pandas pillow   # or: uv add
export TYPESAFE_API_KEY="your-key"               # or put it in a .env file
jupyter lab notebooks/
```

The notebooks find `TYPESAFE_API_KEY` from the environment or from any `.env` file up the
directory tree. A full run of all five notebooks costs well under one cent.

## The elevator pitch (for your intro)

- LLMs generate text for people; Jev returns **typed decisions for code**: a choice with a
  probability per option, a score on your rubric, a probability that a statement is true.
- Trained with **RLCD** (reinforcement learning for calibrated decisions): the probabilities
  are calibrated, so thresholds mean something.
- Around 100 ms and **$0.042 per million input tokens** (output free): two to three orders of
  magnitude cheaper than LLM calls, which makes new architectures affordable (screen every
  message, score every passage, ask speculative questions).
- The discipline: code owns the workflow, Jev answers the judgment calls.
